# View map

Every section of the website split into numbered **views**. A view is the smallest piece of information shown at once. **The text inside each fenced block is copied exactly from `achmadfarizky-content/`** (nothing reworded); only the split points are new.

## How the views were cut

- Split only at paragraph / list-item / table-row boundaries, never inside a paragraph.
- One idea per view, about 70 words at most when paragraphs can be combined. A paragraph longer than that stays whole.
- A heading or label (`**Context**`, `**What I did**`, `### 4a …`) starts a new view and stays with its first paragraph.
- Each quote, each thread, each project, `A moment I'm proud of`, `Tools I picked up` and `→ Related stories` is its own view.
- Tables are split into groups of four rows with the header repeated.
- Home views 1–5 follow the example Achmad wrote (name + headline + intro, then the two further paragraphs, then the three threads one by one).

## Layout templates (suggested, can be changed)

| Code | Template | Used for |
|---|---|---|
| T1 | Hero | First view of Home and of every story |
| T2 | Text + Scene | Default: text on one side, animated 3D scene on the other (a tag for the three threads) |
| T3 | Scene + Caption | Full scene with a short caption, e.g. `A moment I'm proud of` |
| T4 | Quote | Quotes from other people |
| T5 | Grid / List | Tools, projects, certificate rows, related stories |
