Power BI

1. CEO Dashboard

Power BI · July 2025

I rebuilt the CEO dashboard concept from a Nick Desbarats interview. Top managers need to see many dimensions and metrics in about three seconds. I unpivoted everything in the data model so one matrix can show all dimensions at once.

What I learned: 70% of the work was data modeling in Power Query, only 30% was DAX and design.

Tools: Power Query, DAX, matrix visual
